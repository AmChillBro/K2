# K2 Laucher ADG
K2 Launcher ADG is a fork of ProsperoMC, developed by Atlas Development Group. Created as a personal passion project, driven by my love for Minecraft, it aims to improve performance, expand mod compatibility, and push the limits of Minecraft on unconventional platforms.
